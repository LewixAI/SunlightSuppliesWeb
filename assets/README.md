## Read this before using anything

**`masthead/1654078214_masthead-home1.jpg`, `-home2`, `-home3` are stock
photography** — generic blue-rack warehouse renders, not a Sunlight site. Do not
present them as their work. The fourth, `1745392584_masthead_(2).jpg`, **is** their
real Setia Business Park HQ with the signage on the facade, and is the better
hero candidate.

The `gallery/` set is the genuinely valuable material: ten named Johor Bahru
customers, each photo tagged with the system that was installed. That is a
case-study section already written, just not laid out yet.

`cms/` contains files named like `106320175_2700852720016288_..._n.jpg` — these
came off their Facebook page and are real installs, several carrying the SL
watermark in the corner.

## Provenance

`gallery/`, `masthead/`, `cms/`, `products-old/`, `docs/` were downloaded from
`www.sunlightrack.com` itself — its static file tree still serves 200 even though
every page returns HTTP 500. Filenames are theirs, with spaces replaced by
underscores.

`products/`, `projects/`, `site-commy/`, `brand/logo-mark.png` came from the live
`sunlightrack.com.my`.
